# Asad Aman — Portfolio

A responsive personal developer portfolio with layered parallax, project showcases, subtle 3D card tilt, scroll reveals, and reduced-motion support.

## Run locally
Open `index.html` directly, or use any static server.

## Before publishing
Replace `YOUR_EMAIL@example.com` in `index.html` with the preferred email address and update the LinkedIn URL.

## Deploy
Works with Vercel, Netlify, GitHub Pages, or any static hosting provider.
